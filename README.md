# Saroosh Javed — Portfolio

High-end personal site covering the full CV: work, research, experience, skills, education, certifications, and contact.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

The production build lives in `dist/`. Drop it on Netlify, Vercel, or GitHub Pages.

- Netlify: connect the `portfolio` folder, build command `npm run build`, publish directory `dist`
- Vercel: same build command, output `dist`
